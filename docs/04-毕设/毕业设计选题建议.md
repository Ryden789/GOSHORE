# 毕业设计选题：GOSHORE 智能备考工作台

## 题目

**《面向主观题自动评阅的基准约束方法研究及 GOSHORE 智能备考工作台的实现》**

## 一、项目描述

以大语言模型作为评阅器（LLM-as-Judge）对开放性主观题进行自动评分，已具备可行性，但其结果的**可复现性与可解释性不足**：同一份答卷在多次评阅中得分与要点判定存在明显漂移，评分依据难以逐条追溯，导致自动评阅结论在教育与考试场景中缺乏可信度，也难以支撑后续的学习诊断。

本项目针对上述问题提出一种**基准约束式评阅方法（Benchmark-Constrained Grading）**：将人工拆解的结构化采分点基准（子项名称、分值、材料出处）作为外部知识显式注入评阅流程，并对模型输出施加可程序化校验的硬约束——子项分值之和须等于题目满分、每个要点须标注材料出处、禁止模型自创概括词——从而把开放式生成打分转化为**受约束的逐点比对**，使评阅结果具备可复核性与可复现性。方法与系统以申论、公文写作为验证对象，二者均属长文本、采分点隐含于材料之中的主观题型，是该问题最具代表性的场景。

在方法研究基础上，设计与实现 **GOSHORE 智能备考工作台**：客观题侧提供题库管理、限时组卷与用时分析；主观题侧承载上述评阅方法与基准库；评阅产生的失分点经错因归因后进入间隔重复队列，形成"训练—评阅—归因—复习"的完整闭环。系统全部数据本地存储，交付 Web、桌面与移动多端形态。

本课题的技术贡献有三：一是构建带标注一致性检验的主观题评阅基准数据集；二是提出并形式化基准约束式评阅方法，形成可程序化校验的输出契约规则集；三是建立可复现性度量体系（多次评阅方差、要点级一致度、与人工评分相关性），并通过消融实验分离各方法要素的贡献。

## 二、大致需求

**研究性需求**

1. 基准数据集：覆盖归纳概括、综合分析、提出对策、公文写作四类题型，规模不少于 30 题；每题含材料原文、题干、子项采分点与分值分布；由两名标注者独立拆解并计算一致性系数
2. 方法要素可分离：基准注入、契约校验、采分点三档折算三项要素须可独立开关，以支持消融实验
3. 可复现性度量：支持同一答卷重复评阅，统计得分标准差与要点级一致度；支持与人工评分做相关性分析
4. 实验脚手架：批量评阅、盲评协议、结果汇总与统计输出

**工程性需求**

5. 客观题模块：题库管理、按模块组卷、限时整卷与专项训练、断点续做、单题耗时统计与超时题标记
6. 错题归因：知识盲区、审题失误、计算错误、时间不足、蒙猜五类归因与复发标记
7. 主观题模块：基准库按"年份—卷型—题号"组织；双通道评阅（命中基准逐点比对，未命中兜底拆分子项）；失分点三态呈现与材料出处追溯
8. 闭环与呈现：失分点自动入队间隔重复复习；驾驶舱呈现正确率与用时趋势
9. 输入与阅读：答卷拍照识别、长文本阅读
10. 非功能约束：多次评阅得分标准差可控、评阅首字流式响应、数据本地存储、评阅契约链路具备自动化测试

## 三、大概做成什么样

系统为本地运行的单机应用，采用分层结构：**表现层**（驾驶舱与各功能页）、**服务层**（会话、题库、评阅调度、复习调度）、**评阅引擎层**（基准匹配、受约束评阅、契约校验）、**数据层**（题库、基准库、评阅记录、错因与复习队列）。

关键流程为：答卷提交 → 文本结构化 → 基准匹配 → 受约束逐点评阅 → 契约校验 → 要点三态呈现 → 错因归因 → 复习队列。

页面形态：

- 驾驶舱：今日任务、各模块正确率、错题趋势
- 练习页：卷面视图、计时条、答题卡，交卷即时出分与逐题解析
- 评阅页：左侧答卷，右侧要点卡片（命中／部分命中／缺失三态，含分值与材料出处折叠），顶部流式呈现"要点抽取—逐点核对—汇总"进度，底部标注结果来源（基准库或模型自拟）
- 错题页与复习页：按错因分类、一键重做、到期卡片推送

演示方案：现场提交一份答卷，实时展示流式评阅过程与要点级判定结果，并对照同一答卷的多次评阅差异。

## 四、技术架构

| 层次 | 选型 | 技术考量 |
|---|---|---|
| 表现层 | 原生 HTML/CSS/JS，设计变量 token 化 | 无构建链依赖，便于嵌入桌面端与移动端，降低部署复杂度 |
| 服务层 | FastAPI + SSE 流式推送 | 轻量异步框架；流式推送使评阅过程可见，避免长任务黑箱 |
| 评阅引擎 | 大模型 API + 提示约束层 + 输出契约校验 | 核心方法实现：基准注入、逐点比对、三档折算、契约校验 |
| 基准库 | JSON Schema 结构化文件 + 关键词／卷型双路匹配 | 结构可校验、可版本化；支持内置冻结副本实现离线评阅 |
| 数据层 | SQLite | 单机零配置、事务可靠，契合本地化与数据不外传要求 |
| 复习调度 | FSRS 间隔重复模型 | 以记忆稳定性建模复习间隔，优于固定周期策略 |
| 评估工具链 | 独立脚本 + 统计方法 | 计算多次评阅标准差、要点级一致度、与人工评分的相关系数 |
| 交付 | PyInstaller 离线包 / PWA | 桌面免安装运行；移动端以 Web 应用形式交付 |
