## 3. 数据结构契约

政治理论考点使用 `quizzes` 数组（由 `xingce_kb_notes.py` 末尾合并生成，前端不再读单题 `quiz`）：

```python
"quizzes": [
    {
        "q": "题干（以冒号结尾，问「下列说法正确的是」）",
        "options": ["选项1", "选项2", "选项3", "选项4"],  # 不带 A/B/C/D 前缀
        "answer": "B",                                  # A—D
        "explain": "逐项说明错项错在哪、正确项为何正确",
    },
    # …该考点可有多题，顺序为「原题 → 排坑题」
]
```

前端约定：

- 选项字母由前端按索引生成（`"ABCD"[i]`），数据里不写前缀。
- 题干与选项常显；每题一个 `.xc-quiz`，其 `.xc-quiz-ans` 带 `hidden`，点「查看答案与解析」只展开该题，再点收起。
- 一考点多题时，每题上方显示「题目 n / N」。
- 搜索匹配字段：`title` / `body` / 任一 `quizzes[].q`。

## 7. 已知问题（非本次改动引入）

1. **桌面 `run.py` 下打开 `/m/` 报「启动失败：Not Found」**
   - 原因：手机版启动时请求 `/api/auth/me`，该接口只在安卓端 `android/app/src/main/python/goshor_server.py` 实现；桌面 FastAPI 返回 404。
   - 处理：电脑端用 `http://127.0.0.1:8765/`；手机端用 APK 内置服务或 `goshor_server.py`。若要桌面服务兼容 `/m/`，需补 `/api/auth/me` 等兼容接口（独立改动，未做）。

2. **`net::ERR_ABORTED /api/history?limit=3`**
   - 原因：首页请求未返回时刷新/切页，浏览器取消连接；不是 404/500。
   - 现状：接口实测 200；`app.js` 调用处已 `.catch(() => ({items:[]}))` 兜底，不影响页面。

3. **安卓端内容生效**
   - 若 APK 内置 Python 模块与静态资源，需要重新打包才能看到本次新增正文与题目；仅改仓库文件不会自动同步到已安装的 APK。
