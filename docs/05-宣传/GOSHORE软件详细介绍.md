# GOSHORE 上岸自习室

> 软件详细介绍 | V1.0 | 2026-10-07  
> 面向：事业单位联考 C 类备考者及关注本项目的读者

## 一、软件简介

GOSHORE（上岸自习室）是一款面向事业单位联考 C 类备考场景的学习工具。它围绕备考过程中常见的几件事组织功能：寻找题目、安排练习、记录错题、回顾知识点、观察学习情况，并为下一阶段制定训练方向。

软件同时提供桌面和移动使用方式。题库练习、错题复习、知识手册和学习统计等基础能力可在本地使用；AI 辅助和多设备同步属于可选服务，需要用户自行配置。软件不以题目数量代替学习效果，重点是帮助用户把练习、复盘和后续训练连接起来。

**一句话介绍：** 面向 C 类备考的本地学习工作台，帮助用户从刷题走向复习和复盘。

## 二、适合哪些人

- 正在准备事业单位联考 C 类，希望按模块或题型进行练习的考生。
- 想集中整理错题、记录错误原因，并定期回顾的考生。
- 需要用手机进行碎片化练习，或在电脑上完成整卷训练的用户。
- 希望自行准备题目资料、建立个人题库并管理学习记录的用户。
- 希望本地保存个人学习数据，并自行决定是否使用 AI 或同步服务的用户。

## 三、备考中可以怎样使用

### 1. 从日常练习开始

用户可以选择学习入口，按模块、考点或题型练习，也可以进行整卷训练。答题过程中可查看结果、保留需要复习的题目，并继续下一道题。手机使用时提供适合触屏的翻题与底部操作方式。

### 2. 把错题变成复习材料

做错的题目可以进入错题本，用户可回看题目、记录错因、补充个人笔记，并在后续练习中重新检查掌握情况。今日复习和学习计划用于集中处理需要再次练习的内容，减少错题只记录、不回看的情况。

### 3. 了解自己的练习状态

学习统计用于查看答题记录、正确率、模块表现和练习时间。单题用时分析帮助用户发现耗时较长的题目，结合正确率判断问题更可能来自知识点不熟，还是解题速度需要提升。统计结果用于自我观察，不等同于正式能力测评。

### 4. 随时查阅知识点

行测速查手册按模块整理常用考点、规律和技巧；综应手册按主题整理知识内容。用户可以搜索和浏览条目，在练习后回到相关知识点复习。知识资料用于辅助学习，遇到考试政策、标准答案或重要事实时仍应核对官方来源。

## 四、功能介绍

### 4.1 首页与学习安排

- **常用学习入口：** 从首页进入组卷、今日复习、辨析卡或综应相关学习内容。
- **每日目标：** 查看当天答题数量或学习时长的完成情况，帮助形成稳定节奏。
- **考试倒计时：** 根据用户设置的考试日期查看备考时间。
- **学习提醒：** 设置日常学习提醒或考前提醒，也可选择只做计划、不主动提醒。
- **近期记录：** 回看当天和近期的学习情况，了解已完成的练习。

### 4.2 行测题目练习

- **模块练习：** 按常识判断、言语理解、数量关系、判断推理、资料分析等方向开展训练。
- **按考点组卷：** 根据具体知识点或训练目标组织练习内容。
- **整卷训练：** 按 C 类卷面模块顺序进行连续练习，并在结束后查看作答结果。
- **判断专项：** 围绕论证、图形推理、定义、类比和逻辑等题型进行分类练习。
- **资料分析专项：** 进行列式与速算训练，练习常见计算方式和答题节奏。
- **词语填空：** 练习逻辑填空及相关词语辨析内容。
- **空间折叠：** 练习折纸盒等空间推理题型，并提供立体交互与辅助识别相关能力。
- **断点续做：** 中途离开练习后，可回到已保存的答题进度继续完成。

### 4.3 综合应用与主观题学习

综应专区包含科技文献阅读、实验设计、论证评价、校阅改错、科普议论文写作和常识速记等学习内容，也包含申论、时政和面试相关练习入口。用户可以结合自己的考试安排选择模块，不必一次使用所有内容。

部分主观题支持 AI 辅助批改或建议。此类反馈适合用于发现表达和结构上的改进方向，不是官方评分，也不能保证与实际阅卷标准完全一致。

### 4.4 错题、收藏与笔记

- **错题本：** 集中查看需要重新练习的题目。
- **错因记录：** 为错题补充个人原因，帮助识别反复出现的问题。
- **自由笔记：** 在题目下记录解题思路、知识点和复盘结论。
- **收藏：** 保存希望稍后重做或重点查看的题目。
- **错题打印：** 将错题整理为便于线下阅读和复习的页面。
- **状态整理：** 根据复习情况管理题目，减少已掌握内容长期占据待办列表。

### 4.5 词语辨析卡

词语辨析卡用于言语理解和词语积累，可按词语或释义查找。卡片提供多种练习方式：翻转查看、读词回忆释义，以及根据释义选择词语。用户还可以把不熟悉的词单独收集，开展针对性复习。

项目文档记录的卡片规模为 1,150 张，内容由项目内置词表构成。实际使用时可按个人薄弱项筛选，不需要按固定顺序完成全部卡片。

### 4.6 学习资料与进度回顾

- **行测速查：** 项目资料记录覆盖 5 个模块、58 个考点。
- **综应手册：** 项目资料记录覆盖 6 个板块、159 个知识点。
- **学习报告：** 回顾近期练习、错题和模块表现。
- **用时分析：** 找出答题耗时较长的内容，辅助安排提速练习。
- **掌握情况：** 结合练习记录观察不同模块的熟悉程度。
- **考试日期与每日目标：** 将阶段性目标和日常计划放在首页查看。

上述数量来自项目所记录的资料版本；学习资料会随项目内容调整，具体以实际版本为准。

### 4.7 AI 辅助学习

配置 AI 服务后，可在部分题目上获取讲解、提问、生成练习或主观题反馈。AI 的用途是提供额外解释和练习参考，不能保证每次回答都正确。

AI 功能需要网络连接和用户自行准备的服务凭据。用户应避免提交不希望发送到外部服务的个人或敏感信息。未配置 AI 时，基础刷题、复习、统计和本地资料查询仍可使用。

### 4.8 数据备份与跨设备使用

软件提供备份和恢复入口，方便用户保存或迁移自己的学习数据。项目也提供可选的 WebDAV 多设备同步能力，需要用户自行准备兼容的网络存储服务并配置凭据。

建议定期导出备份，并将备份存放在自己可访问且妥善保管的位置。恢复数据前应确认所选文件和目标设备，避免覆盖当前数据。同步配置与使用前，应先阅读应用中的说明并理解数据传输方式。

### 4.9 移动端与个性化体验

- 移动页面支持触屏答题、左右翻题和底部操作入口。
- 可调整显示字号，并选择明暗主题相关设置。
- 首页常用学习入口前移，减少开始练习前的查找步骤。
- 设置页分区在窄屏下自动换行，降低横向拖动导航的需要。
- 可点击列表使用键盘可操作的控件；弹窗支持键盘焦点管理和快捷关闭。
- Android 形态提供独立运行方式；项目记录的 APK 约为 300 MB，安装前应预留足够存储空间。

## 五、几种常见学习流程

### 流程一：日常模块练习

打开首页 → 选择模块或考点 → 完成一组题目 → 查看答题结果 → 将需要巩固的题目留在错题或收藏中 → 通过手册、笔记或再次练习复盘。

### 流程二：整卷自测

选择整卷训练 → 按考试顺序完成各模块 → 交卷并查看结果 → 根据薄弱模块和用时情况安排后续训练。

### 流程三：集中复习错题

打开今日复习或错题本 → 查看历史错题 → 记录错因与解题方法 → 重新作答 → 根据掌握情况继续复习或整理状态。

### 流程四：整理个人题目

准备题目资料 → 从导入入口添加 → 检查题干、选项、答案和解析 → 确认保存 → 使用搜索、组卷和错题功能开展后续学习。

扫描件、公式、图片和复杂排版可能影响识别结果。导入后应抽查题目与答案，确认无误再用于正式练习。

## 六、题库与内容说明

项目 README 和介绍材料记录过本地题库的一个统计快照：23,491 道题目，其中真题 12,393 道；判断推理、资料分析等模块各有对应题量。题库数据库不随公开代码仓库分发，因此上述数字表示项目记录的本地数据版本，不代表每个使用者安装后都会自动获得相同题目。

用户需要自行准备合法题源并建立自己的题库。使用题目资料时应尊重来源版权和使用许可。软件的导入功能只帮助整理内容，不代表项目对题源的版权状态或题目答案作出保证。

## 七、运行方式与开始使用

### 桌面电脑

用户在电脑上启动应用后，可通过浏览器进行题库练习、错题管理、数据查看和设置。Windows 项目目录提供启动入口。首次使用需要准备运行环境，并安装项目所需依赖。

### 手机和平板

手机和平板可以通过移动页面使用。使用电脑提供的移动访问方式时，手机和电脑需要处于允许互相访问的同一网络中。项目也提供 Android 应用形态，适合希望从应用图标直接进入的用户。

### 首次使用建议

1. 先打开首页，了解题库、练习、复习和资料入口。
2. 准备并导入合法题目资料，抽查导入结果。
3. 先完成一组熟悉的模块练习，确认作答、结果和错题流程。
4. 设置考试日期、每日目标和提醒（均可按需启用）。
5. 需要 AI 或跨设备同步时，再单独配置相应服务。
6. 在积累学习记录后定期导出备份。

## 八、使用须知

- **题库需要自行准备：** 公开代码仓库不包含项目介绍中提到的本地题库数据库。
- **AI 是可选能力：** 使用时需要网络和用户自己的服务凭据；AI 输出应核对。
- **主观题反馈仅供参考：** 不代表官方评分，不应据此判断正式考试分数。
- **注意局域网环境：** 当前电脑服务没有登录鉴权。在公共 Wi-Fi、宿舍、公司等共享网络下不建议启动供局域网访问的服务；只在可信网络使用，或限制为本机访问。
- **妥善保管备份：** 备份可能包含个人学习记录，恢复前确认文件和目标位置。
- **核实资料来源：** 使用者需自行确认题源合法，并对导入内容和答案进行检查。
- **合理看待学习数据：** 正确率、用时和掌握情况是个人复习参考，不构成考试结果承诺。

## 九、软件特点与适用边界

### 软件特点

- 面向具体考试场景组织练习、复习、资料和学习记录。
- 将题目练习与错题整理、知识点回顾和进度观察连接起来。
- 支持电脑与移动设备使用，并提供不同的练习方式。
- 基础学习流程可本地开展，AI 和同步由用户按需选择。
- 提供字号、主题、提醒和数据备份等个人使用设置。

### 适用边界

- 软件不能替代官方考试公告、权威教材、教师指导或正式题目来源。
- 项目没有提供真实用户学习效果或通过率的统计证据，不承诺提升幅度。
- AI 生成内容可能出错，重要信息需要用户自行核实。
- 本地题库规模取决于用户实际获得并导入的内容。
- 局域网访问存在无鉴权限制，应按照使用须知选择安全网络环境。
