## 一、产品概述

**上岸题库**是一款专为全国事业单位联考 C 类考试打造的**本地化 AI 题库应用**。它将大平台付费会员专属的核心能力（AI 讲解、模拟考试、学情分析）以**免费、开源、离线**的形式交付给考生，主打"数据在本机、AI 做私教、零会员费"的产品理念。

**一句话定位**：把大平台的会员功能，装进你自己的口袋。

### 产品理念（三个关键词）

| 关键词 | 含义 |
|--------|------|
| **本地** | 题库与作答数据全部存储本机 SQLite，不依赖云端，不上传个人信息 |
| **智能** | DeepSeek 大模型深度参与学习闭环：错题讲解、变式出题、AI 模拟卷 |
| **免费** | 全功能开放、零广告、代码开源于 GitHub，接受公开检验 |

## 二、背景与痛点

当前主流刷题 App 在备考场景中存在三类普遍痛点：

1. **会员墙高**：AI 视频讲解、模考精讲等高价值功能均需付费订阅，长期备考成本高。
2. **体验嘈杂**：开屏广告、课程推销、推送轰炸不断打断刷题心流。
3. **数据上云**：作答记录与错题本存放于平台服务器，用户无法自主掌控，离线场景基本不可用。

上岸题库针对以上痛点逐项给出解法：免费全量功能、纯净无广告界面、题库与数据全本机化。

## 四、核心功能

### 4.1 AI 错题讲解（王牌功能）
- 基于 DeepSeek API，对错题给出**解题思路 + 选项逐项辨析**，而非仅呈现答案。
- 自动生成**同型变式题**，采用"先定答案、倒推数据、自算验证"的生成策略，保证变式题严谨可解。
- 提供 **AI 模拟卷**（列表中以【AI模拟】前缀标识，与真题卷明确区分）。

### 4.2 真题套卷模拟
- 整卷模式完整还原考场：自动倒计时、最后 1 分钟红色闪烁提醒、到点自动交卷结算。

### 4.3 成就激励系统
- 7 级称号体系（按累计答题量从"尚未入列"到顶级称号），首页展示等级与进度条。
- 实时动效成就：10 连对撒花（F-1）、错题歼灭战（F-4）。

### 4.4 学习报告
- 每日结构化战报：今日战况 / 累计成绩 / 错题前线 / 各模块正确率。
- 支持保存（安卓端存至 Download 目录）与直接分享，网页端浏览器下载。

### 4.5 学情看板与辨析卡库
- 正确率趋势、模块强弱分析、周报对比。
- 词语辨析卡库支持 300ms 防抖搜索，按词 / 成语 / 释义检索，与筛选联动，筛选栏滚动吸顶。

### 4.6 内置速查手册（行测 + 综应）
- **行测速查**：5 模块 58 个考点，公式、规律、速算技巧按「一句话结论 + 用法 + 易错提醒」组织，支持搜索与目录跳转。
- **综应考点**：6 板块 159 个知识点（科技文献阅读 / 实验设计 / 论证评价 / 校阅改错 / 科普议论文写作 / 常识速记），手风琴展开。
- 两端渲染规则一致（由 `tools/check_md_parity.mjs` 守着），电脑上排好的版式在手机上不会散。

### 4.7 学习节奏管理
- **断点续做**：中途退出自动存草稿（节流写入 + 心跳 + 切页兜底），回来接着做，题号与已答态完整还原。
- **每日目标**：内联 SVG 进度环，做题数与时长双目标取最小值，连续达标天数。
- **学习提醒**：每日定时提醒 + 考前 7/3/1 天提醒，可开「只计划不打扰」。
- **考试倒计时**：首页横幅按剩余天数分档配色（>30 墨色 / 8~30 靛蓝 / 1~7 朱砂 / 当天 / 过期）。

### 4.8 单题用时分析
- 每题耗时分布、中位数、超时题识别，并区分「不会做」与「会做但超时」——后者往往是提速空间最大的部分。
- 周报附 pace 小结，把时间数据转成可执行的训练建议。

### 4.9 移动端专项优化
- **单手翻题**：底部操作栏 + 左右滑动翻题，底栏跟随每屏重挂（修掉「翻到第 2 题底栏消失」的缺陷）。
- **外观偏好**：夜间模式三态（跟随系统 / 亮 / 暗，防闪烁）+ 字号四档（12.5 / 14.5 / 16.5 / 19px）。
- **安卓桌面小组件**：把倒计时快照推到桌面（launcher 进程不能起 Python，由 APP 推送 SharedPreferences 快照）。

### 4.10 数据自主与多设备
- **错题导出**：生成可打印页，题干内图片经富文本保留，图形题打印不丢图。
- **分级数据清空**：按范围清理，两步确认 + 必须勾选「我确认删除」才可执行。
- **多设备加密同步**：基于 WebDAV（坚果云 / Nextcloud 等），PBKDF2-HMAC-SHA256 派生密钥 + encrypt-then-MAC 信封加密，口令走 Windows DPAPI 落盘，服务端只存密文。
- **备份导出**：走 SQLite 在线备份 API 生成一致性快照 zip，而不是复制正在写入的库文件。

### 4.11 其他细节
- **题目自由笔记**：任意题写笔记，集中浏览、跳回原题。
- **搜题历史**：最近 20 次搜索去重置顶，一键再搜。
- **分享 PK**：生成分享码与他人对拼正确率。

## 五、技术架构

### 5.1 总体架构

```
┌─────────────────────────────────────────────┐
│  前端双端                                    │
│  桌面版 app.js (7,739行)  移动版 m.js (7,213行) │
└──────────────────┬──────────────────────────┘
                   │ HTTP API
┌──────────────────┴──────────────────────────┐
│  后端 FastAPI (Python)                       │
│  题库解析 · 索引检索 · AI 交互 · 学情统计       │
└──────────────────┬──────────────────────────┘
                   │
┌──────────────────┴──────────────────────────┐
│  数据层 SQLite                               │
│  23,491 题库 · 作答记录 · 卡库 · 版本化 _meta  │
└─────────────────────────────────────────────┘
```

> 桌面端与移动端是**两套独立实现**（`static/app.js` / `static/m/m.js`），不共用构建产物。
> 跨端必须一致的逻辑（Markdown 渲染、搜索历史、单手翻题阈值等）以「双端共享块 + 静态校验器」
> 保证：块内容逐字节一致，校验器把真实函数抽出来跑断言。

### 5.2 交付形态

| 形态 | 说明 |
|------|------|
| **网页版** | 电脑启动本地 FastAPI 服务（`start.bat` 一键启动，默认 http://127.0.0.1:8765），手机 / 平板浏览器访问，全平台覆盖；桌面端支持 PWA 安装（manifest + Service Worker + 离线页） |
| **安卓 APP** | WebView 原生壳 + Chaquopy 内置 Python 运行时，APK 约 **299.9 MB**，安装即独立运行，不依赖电脑与网络 |

> 一键拉起：本地服务运行时（`start.bat`），介绍 PPT 结尾页按钮调用 `/api/open_app` 接口，服务端自动发现模拟器并拉起 APP（未安装时自动安装 APK），结果实时反馈；服务未运行时自动降级为 `goshor://` 协议（`tools/install_protocol.bat` 注册），或直接运行 `tools/open_app.bat`。

## 六、质量保障

| 机制 | 说明 |
|------|------|
| 回归自查 | 一键回归流程：编译检查 → 后端 API 验证 → 全部前端页面无头浏览器巡检，**最近一轮全部通过**（pytest **748 条** + 端到端 **72 项断言**全绿，**10 个**静态校验器 EXIT=0） |
| 双端一致性校验 | 桌面端与移动端各有一套实现，凡跨端必须一致的逻辑（Markdown 渲染、搜索历史、单手翻题阈值等）都用「双端共享块 + 静态校验器真跑比对」，并带**篡改自检**（故意改坏后断言必须失败） |
| 启动自检 | `_startup_selfcheck()` 检查 facets / list_exams / 配置加载，异常红色标注 |
| Schema 版本化迁移 | `_meta` 表记录版本号（SCHEMA_VERSION），桌面 `init_db()` 与移动 `connect()` 迁移逻辑保持一致，旧库升级不丢数据 |
| 错误提示分级 | fetch 异常→连接失败；5xx→服务器内部错误；4xx→请求异常并读取 detail |
| 异步竞态防护 | 页面切换采用"渲染 Promise 完成后单次淡入"策略，消除快速切页时旧请求操作已移除 DOM 的竞态 |
| 内容体量下限 | 速查手册/考点库的 pytest 里钉的是**字数与考点数下限**（如综应 ≥140 点 / ≥38000 字），防止内容被静默删薄 |
| 数据安全 | 个人作答记录库与含密钥的配置文件均不入版本库（.gitignore 约束）；同步功能只上传密文 |

## 八、使用方式与获取

- **安卓用户**：安装 APK（约 299.9MB，含 Python 运行时与全量题库），安装即用；演示机上可运行 `tools/open_app.bat` 自动连接模拟器并拉起 APP。
- **全平台用户**：获取源码后运行 `start.bat` 启动服务，浏览器访问 http://127.0.0.1:8765 。
- **开源仓库**：https://github.com/Ryden789/GOSHORE
