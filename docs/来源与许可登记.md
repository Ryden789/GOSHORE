## 一、为什么要这张表

GOSHORE 是**闭源分发**的项目（对外提供 exe 与 APK）。而调研中价值最高的两个项目许可差别极大：

- `liuyuexi1987/xingce-review-pro` 是 **GPL-3.0（强传染）** —— 一旦把它的代码合入 GOSHORE 再闭源分发，整体都要按 GPL 开源
- `jangviktor-web/GongkaoNaoku` 是 **Apache-2.0** —— 可商用、可修改，但要保留 LICENSE/NOTICE 并**声明修改**

两者混用而不登记，会让项目的许可状态在无人察觉的情况下被污染。所以这里按「代码 / 数据 / 文本」三类分开登记，并规定每类能做什么、禁止什么。

## 五、隔离措施

1. **`reference_only/` 只放阅读笔记，不放源码**。该目录被 `.gitignore` 忽略；即使存在，`check_license_guard.py` 也只允许其中的 `.md` / `.txt`，出现任何源码扩展名即报错。
2. **代码目录禁止出现 GPL 头注释**。扫描范围：`app/`、`static/`、`tests/`、`scripts/`、`tools/`、`android/` 与根目录的入口文件；命中即 CI 变红。
3. **引入 Apache-2.0 代码时**，须同步更新 `NOTICE.md` 并注明修改点。
4. **每次引入前在本表新增一行**，未登记不得提交（评审时按本表核对 diff）。
5. 本文件本身**允许**出现 `GPL-3.0` 等字样（它是登记表），因此被排除在扫描范围之外。
