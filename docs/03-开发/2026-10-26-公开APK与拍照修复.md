## 1. 公开 APK：只带示例库

### 构建

```bash
# 1) 从 assets/content-sample.db 生成示例移动资产（不碰本地完整库产物）
python scripts/build_mobile_assets.py --sample
# → .tools/mobile_prep/mobile_assets_sample/
#   共享库 4.2 MB（438 篇）/ 图片 543 个（7.5 MB）/ payload.zip 8.3 MB

# 2) 用示例资产构建 release；versionCode 4 / versionName 1.3
GRADLE=~/.gradle/wrapper/dists/gradle-8.9-bin/*/gradle-8.9/bin/gradle
$GRADLE -p android :app:assembleRelease \
  -PGOSHORE_ASSETS="D:/GOSHORE/.tools/mobile_prep/mobile_assets_sample"

# 3) release 签名（keystore 只在本地，不提交）
apksigner sign --ks .tools/goshore-release.keystore \
  --ks-key-alias goshore --out dist/goshor-sample-20261026.apk \
  android/app/build/outputs/apk/release/app-release-unsigned.apk
```

- `build.gradle` 的 `GOSHORE_ASSETS` 默认仍指向完整资产，开发机构建行为不变；
  只有显式传 `-PGOSHORE_ASSETS=...mobile_assets_sample` 才生成公开包。
- `ndk.abiFilters "arm64-v8a"` 只打一个 ABI；AGP 不允许它与 `splits.abi`
  同时配置，因此不使用 `splits`。
- 示例库是 `assets/content-sample.db`（438 篇，含 240 道精选题），
  公开包不再内置 23,491 篇全量题库。

## 2. 手机拍照：修复 WebView 文件选择器

### 根因

`MainActivity.onShowFileChooser()` 原来对所有文件选择都执行：

```java
intent.setType("application/zip");
```

AI 答疑的 `<input type="file" accept="image/*" capture="environment">`
也不例外，于是手机只弹「选择备份 zip」，相机入口实际不可用。

### 修复

`android/app/src/main/java/com/goshor/app/MainActivity.java`：

- 读取 `FileChooserParams.getAcceptTypes()`；`image/*` 或 `*/*` 走图片分支，
  其他仍走 zip 备份分支。
- `isCaptureEnabled()` 为 true 时发 `MediaStore.ACTION_IMAGE_CAPTURE`，
  照片写入 `cache/camera/photo_*.jpg`，通过 `FileProvider` 授权给相机 App。
- `onActivityResult()` 优先取 `data.getData()`；相机返回 data 为 null 时
  回退到 `pendingCameraUri`，再交给 WebView 的 `ValueCallback`。
- `res/xml/file_paths.xml` 新增 `<cache-path name="camera" path="camera/" />`。
- 相机 Intent 不需要 `CAMERA` 权限；没有声明相机硬件特性，避免安装过滤。

### 验证与限制

- `tests/test_ai_ask.py` 新增 2 条静态契约：Java 使用拍照 Intent +
  FileProvider，前端保留 `capture="environment"`；示例包构建开关与 arm64
  配置也被断言。
- 已构建并签名 APK，检查 `assets/web/m/m.js` 含拍照入口、`classes.dex`
  含 `isCaptureEnabled`；未在真实手机上完成相机唤起验收（本机无 USB 设备，
  模拟器未成功启动）。因此 P0-4 只能算「代码修复 + 构建验证」，
  真机验收仍待补。
- release keystore 仅存在 `.tools/goshore-release.keystore`（gitignore），
  必须备份；丢失后无法对已安装用户升级同一签名。

## 4. 未做与后续

- 示例库只有 438 篇；公开包不覆盖全量 12,393 道真题，这是有意的分发边界。
- 未接 Google Play / 国内应用商店；仍是侧载 APK。
- 真机相机、HEIC、旋转、压缩失败提示需在设备上补验。

  `static/m` 进入下一次移动端构建；桌面端不需要相机文件选择器。
