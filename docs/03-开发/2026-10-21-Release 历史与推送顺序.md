## 维护约定

- 新发布按推送顺序追加为“块 N”，不要按日期重排；历史块只补事实，不改写既有验证数字。
- GitHub Release 页面的说明与本文同步更新；附件大小、SHA256 以 GitHub API/Release 页面为准。
- Release 只分发桌面 exe 与示例题库；APK 仅保留本地归档，避免把 286 MiB 安装包放进 Release。
