## §A 目标与边界

| 编号 | 目标 | 判定方式 |
|---|---|---|
| G1 | 整卷导出/练习的题数与源真题卷一致（如国考副省级 135、地市级 130） | `db.exam_paper_ids(exam)` 返回条数与卷面题量对照 |
| G2 | 题序按卷面科目分区（常识 → 言语 → 数量 → 判断 → 资料），同科内按原题号 | 导出顺序的模块序列不交叉；同模块题号非降 |
| G3 | 组卷页、导出面板、手机组卷页的套卷下拉可搜索（年份 / 省份 / 别名） | 三个入口真实浏览器输入关键词后选项数量符合预期 |
| G4 | 下拉不展示同一真题的残缺旧卷名 | `/api/exams` 返回数与去重规则一致 |

**不做**：
- 不重写题库来源，不删除既有笔记，不改变 `doc_id` 主键（qid 敏感线不动）。
- 不改申论 / 综合分析类卷的导出逻辑。
- 不为搜索引入新的索引表或前端框架。

## §C 方案与取舍

- **选定**：导入时写入 frontmatter `来源科目`，`app/parser.py` 落 `data.src`；`db.exam_paper_ids()` 以 `(模块序号, 来源科目前后, 原题号, id)` 排序。`SRC_RANK` 固定 `01-政治理论=0`、`02-常识判断=1`，其余科目按默认 0。
- **选定**：`db.list_exams()` 按卷名归一（去掉「网友回忆版」与尾括号）分组，同组保留题量最大者，其余只有题量超过完整卷一半才保留，避免「地市级」与「地市级网友回忆版」这类残卷并排出现。
- **选定**：前端新增 `bindExamSearch()`，空格分词、全部包含匹配，`国考 / 省考 / 事业编` 换成卷名中的正式写法；只重排 `<option>`，不改 `select.value` 语义。
- **否决：按 `id` 排序**——依赖入库顺序，补录一题就插错位置。
- **否决：按文件名字符串排序**——文件名含中文与序号，跨科目不稳定。
- **否决：纯前端过滤已渲染的 500 项**——首次仍要渲染 521 个 option；改为按 `<option>` 重建，代价可接受且保持原生下拉。
