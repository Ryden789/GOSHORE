## §C 方案与取舍

- **选定（字体）**：在 `shared/core.js` 新增 `FontFace` 块，偏好键 `fontface`，白名单 `auto/song/hei/kai/yahei`；`apply()` 只写 `document.documentElement.dataset.fontface`；两端 CSS 用 `html[data-fontface="..."]` 覆写 `--serif` / `--sans`，`auto` 不覆写（保持原「宋体标题 + 黑体正文」混排），`--mono` 不动。设置页用胶囊列表，每个胶囊用其自身字体族预览。
- **选定（图标）**：同一份 `ModuleIcon` 块提供六个 32×32 内联 SVG（资料=图表+折线、数量=算盘、判断=九宫格、言语=书页、常识=罗盘、政治=旗帜），`stroke: var(--ink)`、点睛 `var(--cinnabar)`，夜间模式自动跟随；两端 `renderXcNotes` 用 `MI()` 取图标，未知键回退原单字。
- **否决 1（字体）**：内置 Noto / 思源等开源字库。理由：单个中文字库 5—10MB，离线 APK 与网页首屏都不可接受，且需登记许可。
- **否决 2（字体）**：只做一次 `font-family` 覆写写死在 body 上。理由：标题与正文原为两种字体，写死会把标题一起压平；用 CSS 变量才能在保留层级的前提下换族。
- **否决 3（图标）**：继续用汉字单字（政/资/数…）。理由：与「纸墨风」不搭，且在窄屏下与考点数字挤在一起；改用线描图标后语义更直观。
- **否决 4（图标）**：引入图标库或 SVG 图片文件。理由：引外部依赖违反离线要求，且图片无法随夜间模式换色；内联 SVG 走 CSS 变量即可。

## §F 留痕与回滚

- **证据**：`tests/test_appearance.py` F 节 4 项用例；全量 `pytest tests -q` 1210 passed；`scripts/e2e_mobile.py` 88 PASS / EXIT=0；设置页与 `#/xc-notes` 截图（字体胶囊、六图标）；字体生效探针输出。

- **已知局限**：字体依赖系统自带字族，非 Windows 平台（macOS / Android）按回退链落到 `Songti SC` / `Heiti SC` / `PingFang SC` / `Noto Serif SC`，观感与原字体不完全一致，但不会空白；楷体在移动端若缺字，回退到衬线体，笔画差异较明显。
