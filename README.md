# GOSHORE 上岸 · 自习室

面向事业单位 / 公务员联考（C 类）备考的**本地化智能刷题工作台**：本地私有题库 + FastAPI 后端 + 书房纸墨风 Web 界面，电脑与手机同一局域网即可访问；AI 讲题 / 答疑 / 批改基于 DeepSeek API。

- 纯本地运行，学习记录不上传第三方
- 桌面端 `http://127.0.0.1:8765`，手机端 `http://<电脑IP>:8765/m/`
- 支持打包为安卓独立运行版 APK（内置 Python 运行时与数据库）

## 功能特性

### 总览
- **今日 / 周报 / 做题记录**：学习数据统计与回顾
- **AI 答疑**：聊天式提问，支持**图片上传**（拍照问图推题），含图片时自动切换多模态模型；SSE 流式输出，支持快捷提问、历史会话

### 行测精练
- **组卷**：按模块 / 考点自由组卷，考点下拉支持拼音与别名模糊搜索（如「图推」→ 图形推理）
- **C 类整卷**：严格按真实卷面题序（常识→言语→数量→资料→判断→综合分析）
- **判断专项**：论证类型专练（混抽易混类型对比）、图推 / 定义 / 类比 / 逻辑分题型
- **列式专项**：资料分析列式训练
- **词语填空**：逻辑填空练习，空位以全角下划线显示
- **速算**：限时速算挑战，记录最佳成绩
- **空间折叠**：折纸盒题型，支持**拍照录题**（AI 识别展开图）+ three.js 三维折叠交互

### 综应专区
- 申论综应练习、论证评价、科技文献阅读
- **综应考点**：6 组 71 个知识点，搜索过滤 + 手风琴展开
- **AI 批改**：作文 / 综合应用材料智能评分批改

### 复习巩固（艾宾浩斯体系）
- **今日复习 / 错题本 / 收藏**：按遗忘曲线自动排期，错题可标注错因
- **复习驾驶舱**：错题按模块 / 错因聚合，识别反复错题与未标注题
- **辨析卡（词语卡库 1150 张）**：
  - 翻转记忆 / **看词写意（默写）** / **看义选词（测验）** 三种模式
  - 看词写意：默写后基于释义 bigram 匹配**自动评判对错**并显示匹配度，自评可覆盖
  - **不会词本**：标记「不会 / 模糊」的词自动收录，支持专项练习

### 题库管理
- 题库检索（FTS 全文索引）、疑点记录
- 文件导入：支持 PDF / Word / Excel / CSV / MD，AI 抽取题目并做**完整性核对**（缺题如实上报，只入库完整选择题）
- 题库热更新（zip 增量包），难度自动启发式标注

## 技术栈

- **后端**：Python 3.10+ / FastAPI / SQLite（FTS5 全文检索）/ httpx
- **前端**：原生 HTML + CSS + JavaScript（无构建依赖，hash 路由单页应用），「书房纸墨风」设计（米白宣纸底 + 墨色文字 + 朱砂印章色）
- **AI**：DeepSeek API（讲题 / 答疑 / 批改 / 抽题；多模态用 vision 模型）
- **移动端**：WebView 原生壳（轻量版，依赖电脑服务）；独立版用 Chaquopy 内置 Python 运行时 + three.js 三维渲染

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python run.py
#   或 Windows 双击 start.bat（自动释放 8765 端口并打开浏览器）
```

启动后访问：

- 电脑端：http://127.0.0.1:8765
- 手机端：手机与电脑连同一 Wi-Fi，访问启动日志中显示的 `http://<局域网IP>:8765/m/`

### AI 配置

进入页面「设置」填入 **DeepSeek API Key** 即可启用讲题 / 答疑 / 批改功能。Key 使用 Windows **DPAPI 按当前用户加密**落盘（`data/settings.json`），明文不写盘；该文件已在 `.gitignore` 中忽略。

## 项目结构

```
GOSHORE/
├── run.py                 # 启动入口
├── start.bat              # Windows 一键启动
├── app/                   # 后端
│   ├── main.py            # FastAPI 路由（题库/AI/组卷/导入…）
│   ├── db.py              # SQLite 存储层 + 索引 + 迁移
│   ├── ai.py              # DeepSeek 流式对话（含多模态）
│   ├── cube_vision.py     # 折纸盒拍照识别
│   ├── importer.py/parser.py      # 题库导入与解析
│   └── ...                # 速算/列式/论证/综应考点等模块
├── static/                # 前端（无需构建）
│   ├── app.js / styles.css / index.html   # 桌面端
│   ├── m/                 # 手机端
│   ├── cube/              # 空间折叠页（three.js）
│   └── vendor/            # 第三方前端库
├── data/                  # 本地数据（不入仓库）
│   ├── goshor.db          # 题库与学习记录
│   └── settings.json      # API Key（DPAPI 加密）
├── android/               # WebView 壳 / Chaquopy 独立版工程
└── scripts/               # 题库导入与工具脚本
```

## 数据与隐私

- 学习记录、账号、错题等全部存于本地 SQLite，**不包含在 Git 仓库中**（见 `.gitignore`）
- API Key 仅在调用 DeepSeek 服务时使用，本地加密存储
- 备份时请拷贝 `data/` 下的 `accounts.db` 及全部 `data_*.db`
