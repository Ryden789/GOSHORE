# GOSHORE 上岸 · 自习室

面向事业单位 / 公务员联考（C 类）备考的**本地化智能刷题工作台**：本地私有题库 + FastAPI 后端 + 书房纸墨风 Web 界面，电脑与手机同一局域网即可访问；AI 讲题 / 答疑 / 批改基于 DeepSeek API。

- 纯本地运行，学习记录不上传第三方（多设备同步为**端到端加密**的可选功能，见下）
- 桌面端 `http://127.0.0.1:8765`，手机端 `http://<电脑IP>:8765/m/`
- 支持打包为安卓独立运行版 APK（内置 Python 运行时与数据库，无需电脑）

## 功能特性

### 总览
- **今日 / 周报 / 做题记录**：学习数据统计与回顾
- **用时分析**：单题耗时分布、中位数、超时题与「会做但超时」，周报附 pace 小结
- **AI 答疑**：聊天式提问，支持**图片上传**（拍照问图推题），含图片时自动切换多模态模型；SSE 流式输出，支持快捷提问、历史会话
- **考试倒计时**：首页横幅按剩余天数分档配色（>30 墨色 / 8~30 靛蓝 / 1~7 朱砂 / 当天 / 过期）
- **每日目标**：内联 SVG 进度环，做题数与时长双目标取最小值，连续达标天数
- **学习提醒**：每日定时提醒 + 考前 7/3/1 天提醒，支持「只计划不打扰」模式

### 行测精练
- **组卷**：按模块 / 考点自由组卷，考点下拉支持拼音与别名模糊搜索（如「图推」→ 图形推理）
- **C 类整卷**：严格按真实卷面题序（常识→言语→数量→资料→判断→综合分析）
- **判断专项**：论证类型专练（混抽易混类型对比）、图推 / 定义 / 类比 / 逻辑分题型
- **列式专项**：资料分析列式训练
- **词语填空**：逻辑填空练习，空位以全角下划线显示
- **速算**：限时速算挑战，记录最佳成绩
- **空间折叠**：折纸盒题型，支持**拍照录题**（AI 识别展开图）+ three.js 三维折叠交互
- **断点续做**：中途退出自动存草稿，回来接着做（节流写入 + 心跳 + 切页兜底保存）
- **单手翻题**：移动端底部操作栏 + 左右滑动翻题，底栏跟随每屏重挂
- **搜题历史**：记录最近 20 次搜索，去重置顶，一键再搜
- **行测速查**：5 模块 **58 个考点**手册（公式 / 规律 / 速算技巧），搜索过滤 + 目录跳转

### 综应专区
- 申论综应练习、论证评价、科技文献阅读、时政自测、AI 批改、面试模拟
- **综应考点**：6 板块 **159 个知识点**（科技文献 / 实验设计 / 论证评价 / 校阅改错 / 科普议论文 / 常识速记），搜索过滤 + 手风琴展开
- **AI 批改**：作文 / 综合应用材料智能评分批改

### 复习巩固（艾宾浩斯体系）
- **今日复习 / 掌握度图谱 / 学习计划 / 错题本 / 收藏 / 分享 PK**：按遗忘曲线自动排期，错题可标注错因
- **复习驾驶舱**：错题按模块 / 错因聚合，识别反复错题与未标注题
- **题目自由笔记**：任意题写笔记，集中浏览、跳回原题
- **错题导出**：生成可打印页（题干内图片经富文本保留，图形题不丢图）
- **辨析卡（词语卡库 1150 张）**：
  - 翻转记忆 / **看词写意（默写）** / **看义选词（测验）** 三种模式
  - 看词写意：默写后基于释义 bigram 匹配**自动评判对错**并显示匹配度，自评可覆盖
  - **不会词本**：标记「不会 / 模糊」的词自动收录，支持专项练习

### 题库管理
- 题库检索（FTS5 全文索引）、疑点记录
- 文件导入：支持 PDF / Word / Excel / CSV / MD，AI 抽取题目并做**完整性核对**（缺题如实上报，只入库完整选择题）
- 题库热更新（zip 增量包），难度自动启发式标注
- **分级数据清空**：按范围清理，两步确认 + 必须勾选「我确认删除」才可执行
- **多设备加密同步**：基于 WebDAV（坚果云 / Nextcloud 等），PBKDF2-HMAC-SHA256 派生密钥 + encrypt-then-MAC 信封加密，口令走 Windows DPAPI 落盘，服务端只存密文
- **外观偏好**：夜间模式三态（跟随系统 / 亮 / 暗）+ 字号四档（12.5 / 14.5 / 16.5 / 19px），刷新不闪烁
- **安卓桌面小组件**：把倒计时快照推到桌面（launcher 进程不能起 Python，由 APP 推送 SharedPreferences 快照）

## 技术栈

- **后端**：Python 3.13 / FastAPI / SQLite（FTS5 全文检索）/ httpx
- **前端**：原生 HTML + CSS + JavaScript（无构建依赖，hash 路由单页应用），「书房纸墨风」设计（米白宣纸底 + 墨色文字 + 朱砂印章色）；桌面端与移动端各一套独立实现（`static/app.js` / `static/m/m.js`）
- **AI**：DeepSeek API（讲题 / 答疑 / 批改 / 抽题；多模态用 vision 模型）
- **移动端**：WebView 原生壳（轻量版，依赖电脑服务）；独立版用 Chaquopy 内置 Python 运行时 + three.js 三维渲染
- **桌面端**：支持 PWA 安装（`manifest-desktop.webmanifest` + Service Worker + 离线页）

## 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务
python run.py
#   或 Windows 双击 start.bat（自动释放 8765 端口并打开浏览器）
```

启动后访问：

- 电脑端：http://127.0.0.1:8765
- 手机端：手机与电脑连同一 Wi-Fi，访问启动日志中显示的 `http://<局域网IP>:8765/m/`

### AI 配置

进入页面「设置」填入 **DeepSeek API Key** 即可启用讲题 / 答疑 / 批改功能。Key 使用 Windows **DPAPI 按当前用户加密**落盘（`data/settings.json`），明文不写盘；该文件已在 `.gitignore` 中忽略。多设备同步的 WebDAV 密码与同步口令同样走 DPAPI。

## 数据与隐私

- 学习记录、账号、错题等全部存于本地 SQLite，**不包含在 Git 仓库中**（见 `.gitignore`）
- API Key 仅在调用 DeepSeek 服务时使用，本地加密存储
- 备份请用页面内的**导出备份**（`/api/backup/export`，走 SQLite 在线备份 API 生成一致性快照 zip），而不是直接复制正在写入的 `.db` 文件
- 手动备份需覆盖：`data/goshor.db`（桌面端题库与记录）、`data/users/`（移动端 `accounts.db` + `data_<uid>.db`）、`data/settings.json`、`data/essay_questions.json`
- 多设备同步走 WebDAV 时**只上传加密后的密文**，同步口令不落明文
